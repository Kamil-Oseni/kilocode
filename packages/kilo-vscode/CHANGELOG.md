# Raya changelog

## 7.4.23

- Added persistent goals with visible progress, steering, verification, review, continuation, and checkpoint-based discard.
- Added a global self-healing feedback backlog that launches isolated repair goals and records outcomes.
- Added intelligent Chief routing, specialist delegation, configurable model mappings, and a small-model path for direct tasks.
- Added configurable speech-to-text, MiniMax streaming speech output, push-to-talk, hands-free mode, and interruption handling.
- Added the integrated browser, authenticated walkthrough capture, browser smoke tests, and cross-platform browser shortcut.
- Added provider management, settings import/export, project-aware configuration, and encrypted secret storage.
- Added historical token and cost analytics by model with selectable time ranges.
- Added the Eden visual foundation with Instrument Serif, Outfit, semantic tokens, and a local preview harness.
- Added inline green/red change review with per-change Keep and Discard controls.
- Improved Qwen multimodal delivery, DeepSeek DSML tool-call recovery, Windows path behavior, and extension packaging.
