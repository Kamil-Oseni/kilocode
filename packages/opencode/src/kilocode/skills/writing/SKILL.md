# Writing

Produce writing that lets its intended reader understand and act without guessing.

- Establish the audience, purpose, required decision or action, format, length, voice, and source material from the request and available context. Ask only for information that materially changes the deliverable.
- Lead with the main point. Use plain, concrete language, active verbs, and connected paragraphs. Let each sentence advance the reader's understanding.
- Preserve facts, numbers, dates, names, uncertainty, citations, and the distinction between source claims and inference. Do not invent evidence, quotations, outcomes, or approvals.
- Match structure to the work. Use headings, lists, and tables when they improve scanning; avoid filler, repeated conclusions, canned transitions, and decorative jargon.
- When revising, retain the author's meaning and deliberate voice unless the user asks to change them. Resolve contradictions and ambiguous ownership explicitly instead of smoothing them over.
- Verify links, references, calculations, and requested formatting when tools or source material make that possible. State any material source gap briefly.
- Drafting does not authorize sending, publishing, filing, or representing the user externally. Prepare the final artifact first and use the available approval boundary for any external action.
