// raya_change - Milestone D intelligent subagent calling
Launch a new isolated agent to handle complex, multistep tasks autonomously.

Subagent selection is automatic by default. Omit subagent_type (or use "auto") so the Chief router selects the best-fit specialist from the structured brief. Set an explicit subagent_type only when the user requests that specialist or automatic routing cannot express a hard requirement.

Provide brief.objective and include relevant context, constraints, and the expected synthesized return. The child must return conclusions, evidence, and artifact paths rather than its raw transcript.

When NOT to use the Task tool:
- If you want to read a specific file path, use the Read or Glob tool instead of the Task tool, to find the match more quickly
- If you are searching for a specific class definition like "class Foo", use the Grep tool instead, to find the match more quickly
- If you are searching for code within a specific file or set of 2-3 files, use the Read tool instead of the Task tool, to find the match more quickly
- If no available agent is a good fit for the task, use other tools directly


Usage notes:
1. Launch multiple agents concurrently whenever possible, to maximize performance; to do that, use a single message with multiple tool uses
2. Parallel foreground calls join before your next model step. Synthesize all returned results; do not finish while required background calls are still running.
3. Once you have delegated work to an agent, do not duplicate that work yourself. Continue with non-overlapping tasks, or wait for the result. For background tasks, you will be notified automatically when the result is ready.
4. When the agent is done, it returns one synthesized message. The output includes a task_id you can reuse later to continue the same isolated child session.
5. Each agent invocation starts with fresh context unless you provide task_id. Put all necessary information in the structured brief.
6. The agent's synthesized outputs should generally be trusted.
7. Clearly state whether the child should edit or only research, and include required verification.
8. If an agent description says it should be used proactively, prefer it when the brief matches.
