# Native capture candidate

`desktop-capture.cpp` is an isolated Windows DXGI Desktop Duplication host. It is not packaged or launched by Raya yet. Build it with `script/build-desktop-capture.ps1`; the default output is a temporary executable. Standard output is reserved for binary packets, so do not run it in a text-only pipeline.

Each packet is a 32-bit little-endian JSON-header length (1–4096), that many UTF-8 JSON bytes, a 32-bit little-endian image length (0–15,000,000), and optional PNG bytes. Successful headers have `v:1`, `type:"frame"`, a positive monotonic `sequence`, exact foreground `windowID` and `location`, physical `width`/`height`, `mime:"image/png"`, `acquisitionMs`, and `preparationMs`. Terminal failures have `v:1`, `type:"error"`, a lowercase `code`, and zero image bytes. They never include window details. The consumer must reject truncated packets, protocol violations, changed targets, and unknown sequences.

The host samples the visible foreground window only when its entire rectangle lies in one unrotated monitor. It compares exact foreground identity and bounds before acquisition, after acquisition, and before sending each image. It stops on device loss, unsupported format, monitor crossing, target change, or any other ambiguous capture result. A changed or occluded window may still display other applications' pixels; this is a *desktop* capture, not a private-window capture. Cursor compositing, dirty-region transport, HDR, rotated monitors, and cross-monitor windows are not implemented. The extension must retain its current fail-closed backend until this candidate passes live target, cancellation, performance, and restart testing.

Memory is bounded by a DXGI output capped at 16,588,800 pixels, one cropped CPU texture of at most 8,294,400 pixels, and one fixed 15 MB PNG output buffer. WIC's memory stream cannot grow past that buffer, and the host checks the PNG end marker to report its exact length. Raw pixels are not persisted. The host checks a console stop signal between at-most-50 ms acquisition waits; a supervising extension should terminate the process and cancel its pipe on grant revocation. A blocked pipe write is interrupted by pipe closure or process termination. No terminal frame is silently replayed.
